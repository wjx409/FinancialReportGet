## 2. 技术选型

| 层级 | 技术 |
|------|------|
| 前端 | React 18 + Vite + TailwindCSS + 纯 CSS 动画 |
| 后端 | Python 3 + FastAPI（异步支持好，天然支持 WebSocket） |
| 文件处理 | openpyxl（读取 Excel）、python-multipart（上传） |
| 实时通信 | FastAPI WebSocket（服务端推送进度） |
| 临时存储 | 本地文件系统（/tmp 目录，过期清理） |

## 3. 路由定义

| 路由 | 方法 | 说明 |
|------|------|------|
| `GET /` | GET | 返回前端单页 HTML |
| `POST /upload` | POST | 接收 Excel 文件，启动处理任务，返回 task_id |
| `GET /ws/{task_id}` | WebSocket | 实时推送处理进度 |
| `GET /result/{task_id}` | GET | 返回结果摘要 JSON |
| `GET /download/{task_id}` | GET | 下载结果 Excel 文件 |
| `DELETE /task/{task_id}` | DELETE | 清理任务及临时文件 |

## 4. API 详细定义

### 4.1 POST /upload

**请求**：`multipart/form-data`，字段 `file`（.xlsx）

**响应 200**：
```json
{
  "task_id": "uuid-string",
  "total_rows": 50,
  "filename": "机构名单.xlsx"
}
```

**响应 400**：文件格式错误或大小超限

### 4.2 WebSocket /ws/{task_id}

**服务端推送消息**（JSON）：

```json
// 进度更新
{ "type": "progress", "current": 10, "total": 50, "status": "成功", "title": "2025年年度报告", "code": "000001" }

// 完成
{ "type": "done", "success_count": 48, "fail_count": 2, "task_id": "uuid-string" }

// 错误
{ "type": "error", "message": "文件处理失败" }
```

### 4.3 GET /download/{task_id}

**响应**：Content-Type: `application/vnd.openxmlformats-officedocument.spreadsheetml.sheet`，Content-Disposition: `attachment; filename="机构名单_财报链接_2025.xlsx"`

## 5. 数据模型

### 5.1 任务状态（内存/文件系统）

```python
class TaskState:
    task_id: str          # UUID
    filename: str          # 原始文件名
    total_rows: int        # 总行数
    success_count: int     # 成功数
    fail_count: int        # 失败数
    status: str            # pending / processing / done / error
    results: List[RowResult]  # 每行的处理结果
    result_file_path: str  # 生成的 Excel 文件路径

class RowResult:
    row_index: int
    code: str
    name: str
    title: str
    url: str
    publish_date: str
    status: str
```

## 6. 核心处理流程

1. `POST /upload` 接收文件 → 保存到 `/tmp/{task_id}/input.xlsx`
2. 使用 `openpyxl` 读取 Excel，解析表头，找到证券代码/公司名称列
3. 为每行调用 `fetch_latest_report()`（来自 `financial_report_fetcher.py` 的核心逻辑）
4. 每处理完一行立即通过 WebSocket 推送进度
5. 所有行处理完毕后，生成结果 Excel（追加三列：最新财报标题、最新财报链接、最新财报发布时间），保存为 `/tmp/{task_id}/output.xlsx`
6. WebSocket 推送 `done` 消息，附上 `task_id`
7. `GET /download/{task_id}` 读取结果文件流式返回

## 7. 安全与限制

- 仅接受 `.xlsx` 扩展名，Magic byte 校验（ZIP/XLSX 均以 PK 开头）
- 文件大小上限：10MB
- 单个任务最多 500 行，超出返回 400
- 临时文件 24 小时后自动清理（后台定时任务）
- 后端不对外暴露内部接口，仅通过 API 访问
