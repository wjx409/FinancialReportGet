# 产品需求文档（PRD）- 财报链接获取工具 Web 版

## 1. 产品概述

一款在线工具，将本地 Python 财报批量获取脚本包装为 Web 界面。用户上传含机构名单的 Excel 文件，系统自动调用巨潮资讯接口获取每家机构的最新财报 PDF 链接，生成含链接的结果文件供下载。

- **目标用户**：金融从业者、分析师、投资者
- **核心价值**：省去逐个搜索的手动操作，一键批量获取多家机构的财报下载链接
- **市场定位**：轻量级、免安装、即用即走的在线工具

## 2. 功能模块

### 2.1 用户角色

| 角色 | 说明 |
|------|------|
| 普通用户 | 直接使用，无需注册登录，直接上传 Excel 获取结果 |

### 2.2 功能模块

1. **首页/上传页**：拖拽/选择 Excel 文件，显示文件预览，开始处理
2. **处理进度页**：实时展示每行数据处理状态，成功/失败统计，进度条
3. **结果下载页**：展示处理结果摘要，一键下载含链接的 Excel 文件

## 3. 核心流程

```
┌──────────────┐    ┌──────────────────┐    ┌────────────────┐
│  上传 Excel  │ -> │  后端逐行查询接口 │ -> │  生成结果 Excel │
└──────────────┘    └──────────────────┘    └────────────────┘
                          ↓
                   WebSocket 推送进度
```

**详细用户流程：**
1. 用户打开页面，拖拽或点击选择 .xlsx 文件
2. 前端校验文件格式，解析表头显示预览
3. 用户点击"开始获取"，文件上传至后端
4. 后端使用 Python 脚本处理，每处理完一行通过 WebSocket 推送进度
5. 前端实时显示：当前处理行、成功数、失败数
6. 所有行处理完毕后，显示"下载结果"按钮
7. 用户点击下载，获取含「最新财报标题」「最新财报链接」「发布时间」三列的 Excel 文件

## 4. UI 设计风格

### 4.1 设计方向：金融终端风格（FinTech Terminal）

- **色调**：深空蓝背景（#0D1117） + 荧光绿强调色（#00E5A0）+ 冰蓝色（#58A6FF）
- **主色调**：深空黑/深蓝（#0D1117, #161B22）
- **强调色**：荧光绿 / 电光蓝（#00E5A0, #58A6FF）
- **文字色**：主文字 #E6EDF3，次级文字 #8B949E
- **字体**：JetBrains Mono（数据展示）+ Noto Sans SC（界面说明）
- **按钮风格**：圆角矩形，霓虹边框光晕效果，hover 时发光增强
- **布局**：顶部标题栏 + 居中上传区 + 下方进度/结果区，三段式布局
- **动效**：
  - 页面加载：标题与上传区错帧淡入（staggered fade-in）
  - 文件拖入：上传区发光脉冲动画
  - 进度更新：数字滚动动画 + 进度条流畅过渡
  - 结果展示：表格行依次滑入

### 4.2 页面设计

#### 页面：上传与处理主页（单页应用）

| 模块 | UI 元素 |
|------|---------|
| 顶部标题栏 | 工具名称 + 副标题，进度指示器（空闲/处理中/完成） |
| 上传区 | 虚线边框拖拽区，支持点击上传，显示已选文件名 |
| 文件预览 | 表格展示表头 + 前 5 行数据 |
| 配置区 | 显示 TARGET_YEAR 参数（当前：2025），不可编辑 |
| 操作区 | "开始获取"按钮（处理中显示加载动画 + "处理中…N/M"） |
| 进度区 | 进度条 + 实时日志列表（滚动，最新在上） |
| 结果区 | 汇总统计（成功数/失败数）+ 预览表格（部分列）+ 下载按钮 |

### 4.3 响应式

- 桌面端优先（1200px+），平板适配（768px），移动端可读但非优化重点
- 表格横向滚动，移动端不压缩列宽

## 5. 非功能性需求

- **性能**：支持最多 500 行数据处理，单行查询间隔 0.8s，最长等待约 7 分钟
- **安全**：仅接收 .xlsx 文件，文件大小限制 10MB，后端对文件做白名单扩展名校验
- **可靠性**：查询失败自动重试 3 次，单行失败不影响其他行
- **可访问性**：支持键盘操作，错误状态有文字提示
